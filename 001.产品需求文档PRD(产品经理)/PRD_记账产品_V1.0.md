## 2. 产品概述

### 2.1 产品愿景

帮助每一个人轻松掌握自己的财务状况——让记账变成一种习惯，而非负担。

### 2.2 产品定位

面向个人用户的轻量级收支记账工具，支持 iOS、Android 及 Web 端，聚焦**「快速录入 + 可视化分析」**，让用户在 10 秒内完成一笔记录。

### 2.3 目标用户画像

| 用户类型 | 特征描述 | 核心诉求 |
|----------|----------|----------|
| 职场新人 | 月薪 5K-15K，刚独立生活，缺乏财务规划意识 | 了解钱花在哪了，建立储蓄习惯 |
| 家庭主理人 | 管理家庭日常支出，需要与伴侣共享账本 | 分类清晰、家庭共账、月度报告 |
| 自由职业者 | 收入不稳定，需要分项目/来源追踪 | 多收入来源管理、税前税后计算 |
| 精打细算达人 | 已有记账习惯，希望深度分析 | 自定义分类、预算告警、趋势图表 |

## 3. 市场与竞品分析

### 3.1 市场背景

- 个人理财 App 市场规模持续增长，移动端渗透率持续提升
- 用户主要痛点：操作繁琐、功能臃肿、存在隐私担忧
- 市场机会：极简快速录入 + 智能分类 + 数据本地优先

### 3.2 竞品对比

| 竞品 | 优势 | 不足 | 差异化机会 |
|------|------|------|------------|
| 随手记 | 功能全面，用户基数大 | 界面老旧，广告较多 | 更清爽的 UI，无广告干扰 |
| MoneyMoney | 数据可视化好 | 仅桌面端 | 移动端同等可视化体验 |
| 鲨鱼记账 | 极简设计 | 分析功能薄弱 | 极简 + 深度分析兼顾 |
| **本产品** | 快速录入 + 可视化 + 隐私安全 | — | 10 秒录入 + 本地加密存储 |

## 4. 产品目标与成功指标

### 4.1 产品目标（OKR）

| 目标（O） | 关键结果（KR） | 衡量周期 |
|-----------|----------------|----------|
| 提升录入效率 | 单笔记录平均耗时 ≤ 10 秒 | 每月 |

| 保障数据安全 | 用户数据本地加密，零服务端泄漏事件 | 持续 |

## 5. 功能需求

### 5.1 功能优先级矩阵（MoSCoW）

| 优先级 | 含义 | 功能项 |
|--------|------|--------|
| **Must Have（必须有）** | MVP 核心功能，缺失则产品不可用 | 收支录入、分类管理、日/月账单列表、余额统计 |
| **Should Have（应该有）** | 重要功能，提升使用体验 | 预算设置、收支图表、数据导出、搜索过滤 |
| **Could Have（可以有）** | 锦上添花 | 多账本、共享账本、周期性账单、智能分类建议 |
| **Won't Have（暂不做）** | 本期不做 | 银行卡自动同步、投资组合管理 |

### 5.2 核心功能详细说明

#### 5.2.1 快速记账

用户核心高频操作，设计目标是「三步完成记录」。

**录入字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 账单类型 | 单选（支出 / 收入） | 是 | 默认选中「支出」 |
| 金额 | 数字输入 | 是 | 支持小数点两位，自动弹出数字键盘 |
| 分类 | 分类选择器 | 是 | 图标 + 文字，展示 8 个常用，支持展开更多 |
| 日期时间 | 日期时间选择器 | 是 | 默认为当前时间 |
| 备注 | 文本输入 | 否 | 最多 100 字 |
| 账本 | 单选 | 否 | 默认「日常账本」 |

**交互规则：**

- 点击底部「+ 记账」按钮，底部抽屉式面板弹出
- 数字键盘自动弹出，用户可直接输入金额
- 分类支持自定义，可修改名称和图标
- 保存成功后面板收起，列表自动更新并高亮新条目（300ms 动效）

#### 5.2.2 账单列表

- 按日期分组，最新日期置顶，每日显示小计金额
- 每条记录展示：分类图标、分类名称、备注（截断显示）、金额（支出红色 / 收入绿色）、时间
- 左滑条目显示：编辑 / 删除操作
- 支持按月份切换，顶部显示本月总收入、总支出、结余

#### 5.2.3 统计分析

| 图表类型 | 说明 | 维度 |
|----------|------|------|
| 饼图 / 环形图 | 各分类支出占比 | 月度 / 年度 |
| 柱状图 | 每日 / 每周收支对比 | 月视图 |
| 折线图 | 月度收支趋势 | 近 6 / 12 个月 |
| 排行榜 | 支出最多的 Top 5 分类 | 月度 / 年度 |

#### 5.2.4 预算管理

- 支持设置月度总预算和分类预算
- 预算进度条：已用 / 总预算（百分比 + 金额）
- 预警机制：达到 80% 时推送通知，达到 100% 时红色告警标识

#### 5.2.5 数据管理

- 导出格式：CSV、Excel（.xlsx）
- 导出范围：自定义日期区间
- 数据备份：支持导出完整备份文件（JSON），可导入恢复
- 数据删除：支持清空账本（需二次确认弹窗）

## 6. 信息架构

应用共 4 个主 Tab：

| Tab | 页面 | 核心内容 |
|-----|------|----------|
| 首页 | 账单列表 | 当月收支摘要 + 按日分组账单列表 + 浮动记账按钮 |
| 统计 | 数据分析 | 图表（饼图 / 柱图 / 折线图）+ 分类排行 |
| 预算 | 预算管理 | 总预算进度 + 分类预算列表 |
| 我的 | 设置中心 | 账本管理、分类管理、数据导入导出、外观设置、关于 |

## 7. 关键用户流程

### 7.1 新用户首次使用流程

1. 打开 App → 欢迎页（3 张功能引导图）
2. 选择货币单位（默认人民币 ¥）
3. 可选：设置月度总预算
4. 进入首页，弹出「记第一笔账」引导气泡
5. 完成第一笔记录 → 展示成就动效「开始记账了！」

### 7.2 日常记账流程

1. 点击「+ 记账」按钮
2. 输入金额
3. 选择分类
4. （可选）添加备注、修改日期
5. 点击「保存」→ 完成

### 7.3 月度复盘流程

1. 进入「统计」Tab
2. 查看本月支出饼图 → 识别最大开销分类
3. 对比预算执行情况
4. 导出月度报告（CSV）备存

## 8. 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 首屏加载 ≤ 2s；账单列表滚动帧率 ≥ 60fps；图表渲染 ≤ 500ms |
| 稳定性 | Crash 率 ≤ 0.1%；ANR 率 ≤ 0.05% |
| 安全性 | 本地数据 AES-256 加密；支持生物识别（Face ID / 指纹）解锁 |
| 兼容性 | iOS 15+、Android 9+、主流浏览器（Chrome 90+、Safari 15+） |
| 可访问性 | 支持系统字体大小缩放；色盲模式（收支用图案区分，不仅依赖颜色） |
| 离线支持 | 核心记账功能完全离线可用；云同步为可选付费功能 |

## 9. 核心数据模型

| 实体 | 关键字段 |
|------|----------|
| 账单（Record） | id, type(income/expense), amount, category_id, account_id, date, note, created_at |
| 分类（Category） | id, name, icon, type(income/expense), sort_order, is_custom |
| 账本（Account） | id, name, currency, balance, created_at |
| 预算（Budget） | id, month, total_amount, category_id（可为空）, account_id |

## 11. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| 用户数据丢失 | 低 | 高 | 本地自动备份 + 定期导出提醒 |
| 分类不满足用户习惯 | 中 | 中 | 提供完整自定义分类能力，内置 30+ 预设分类 |
| 用户粘性不足 | 中 | 高 | 每日记账提醒 + 月度财务报告 Push |
| 隐私合规问题 | 低 | 高 | 数据本地存储优先，明确隐私政策，不强制联网 |

## 12. 附录

### 12.1 预设收支分类

| 类型 | 预设分类 |
|------|----------|
| 支出 | 餐饮、交通、购物、娱乐、住房、医疗、教育、人情、宠物、旅行、运动、订阅、其他支出 |

### 12.2 术语表

| 术语 | 定义 |
|------|------|
| 账本 | 一组账单的集合，一个用户可拥有多个账本（如「日常」「旅行」） |
| 结余 | 当前周期内总收入 - 总支出 |
| 预算达成率 | 当前支出 / 设定预算 × 100% |
| 周期性账单 | 按固定周期自动生成的账单条目（如每月房租） |
