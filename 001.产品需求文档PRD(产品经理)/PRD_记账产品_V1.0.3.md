## 2. 产品概述

### 2.1 产品愿景

帮助每一个人轻松掌握自己的财务状况——让记账变成一种习惯，而非负担。

### 2.2 产品定位

面向个人用户的轻量级收支记账工具，支持 iOS、Android 及 Web 端，聚焦**「快速录入 + 可视化分析」**，让用户在 10 秒内完成一笔记录。产品采用中国水墨风视觉语言，在工具类产品中形成独特的东方美学辨识度。

### 2.3 目标用户画像

| 用户类型 | 特征描述 | 核心诉求 |
|----------|----------|----------|
| 职场新人 | 月薪 5K-15K，刚独立生活，缺乏财务规划意识 | 了解钱花在哪了，建立储蓄习惯 |
| 家庭主理人 | 管理家庭日常支出，需要与伴侣共享账本 | 分类清晰、家庭共账、月度报告 |
| 自由职业者 | 收入不稳定，需要分项目/来源追踪 | 多收入来源管理，税前税后计算 |
| 精打细算达人 | 已有记账习惯，希望深度分析 | 自定义分类、预算告警、趋势图表 |

## 3. 市场与竞品分析

### 3.1 市场背景

- 个人理财 App 市场规模持续增长，移动端渗透率持续提升
- 用户主要痛点：操作繁琐、功能臃肿、存在隐私担忧
- 市场机会：极简快速录入 + 智能分类 + 数据本地优先

### 3.2 竞品对比

| 竞品 | 优势 | 不足 | 差异化机会 |
|------|------|------|------------|
| 随手记 | 功能全面，用户基数大 | 界面老旧，广告较多 | 更清爽的 UI，无广告干扰 |
| MoneyMoney | 数据可视化好 | 仅桌面端 | 移动端同等可视化体验 |
| 鲨鱼记账 | 极简设计 | 分析功能薄弱 | 极简 + 深度分析兼顾 |
| **本产品** | 水墨风美学 + 快速录入 + 隐私安全 | — | 东方美学差异化 + 10 秒录入 + 本地加密 |

## 4. 产品目标与成功指标

### 4.1 产品目标（OKR）

| 目标（O） | 关键结果（KR） | 衡量周期 |
|-----------|----------------|----------|
| 提升录入效率 | 单笔记录平均耗时 ≤ 10 秒 | 每月 |

| 保障数据安全 | 用户数据本地加密，零服务端泄漏事件 | 持续 |

## 5. 功能需求

### 5.1 功能优先级矩阵（MoSCoW）

| 优先级 | 含义 | 功能项 |
|--------|------|--------|
| **Must Have（必须有）** | MVP 核心功能，缺失则产品不可用 | **登录 / 注册 / 找回密码**、收支录入、分类管理、日/月账单列表、余额统计 |
| **Should Have（应该有）** | 重要功能，提升使用体验 | 预算设置、收支图表、数据导出、搜索过滤 |
| **Could Have（可以有）** | 锦上添花 | 多账本、共享账本、周期性账单、智能分类建议 |
| **Won't Have（暂不做）** | 本期不做 | 银行卡自动同步，投资组合管理 |

### 5.2 核心功能详细说明

#### 5.2.1 登录与注册

用户身份认证入口，采用最简化设计，降低注册门槛。

**注册流程字段：**

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| 用户名 | 文本输入 | 是 | 4-20 位字符，支持汉字、字母、数字、下划线；不可重复 |
| 密码 | 密码输入 | 是 | 8-20 位，须包含字母和数字 |
| 确认密码 | 密码输入 | 是 | 须与密码一致 |

**登录流程字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 用户名 | 文本输入 | 是 | — |
| 密码 | 密码输入 | 是 | 支持「显示/隐藏密码」切换 |

**交互规则：**

- App 首次打开 → 进入落地页；已登录状态直接进入首页
- 落地页提供「开启记账之旅」（注册入口）和「立即登录」（登录入口）两个 CTA
- 登录页提供「立即注册」入口，注册成功后自动登录跳转首页
- 密码存储使用 bcrypt 哈希，不明文保存
- 登录失败连续 5 次后，锁定账号 10 分钟并提示
- 支持「记住登录状态」（默认勾选），Token 有效期 30 天

**页面结构（登录页）：**
- 水墨风 Logo + 产品名「留白记账」
- 用户名/手机号输入框（带左侧图标）
- 密码输入框（带显示/隐藏切换按钮）
- 记住登录状态复选框
- 登录按钮
- 「忘记密码？」链接
- 毛笔装饰分割线
- 「初识留白？」注册入口

**页面结构（注册页）：**
- 顶部导航栏（返回 + 标题）
- 手机号 / 用户名 / 密码 / 确认密码 四个输入框（带左侧图标）
- 密码显示/隐藏切换
- 服务协议勾选
- 「开启记账之旅」主按钮
- 已有账号？立即登录

#### 5.2.2 找回密码（V1.0.3 完善）

**页面结构（单页表单）：**
- 顶部导航栏（返回 + 标题）
- 锁定重置图标 + 引导文字
- 手机号输入框（带左侧图标）
- 验证码输入框（带「发送验证码」按钮）
- 新密码输入框（带显示/隐藏切换按钮）
- 确认新密码输入框（带显示/隐藏切换按钮）
- 「重置」按钮

**交互规则：**

- 发送验证码后 60 秒倒计时
- 表单校验：手机号 11 位、验证码至少 4 位、新密码 8-20 位且包含字母和数字、两次密码一致
- 重置成功后跳转成功页，点击「返回登录」跳转登录页

#### 5.2.3 快速记账

用户核心高频操作，设计目标是「三步完成记录」。

**录入字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 账单类型 | 单选（支出 / 收入） | 是 | 默认选中「支出」 |
| 金额 | 数字输入 | 是 | 支持小数点两位，数字键盘输入 |
| 分类 | 分类选择器 | 是 | 图标 + 文字，4×2 网格展示 |
| 日期时间 | 日期时间选择器 | 是 | 默认为当前时间 |
| 备注 | 文本输入 | 否 | 最多 100 字 |
| 账本 | 单选 | 否 | 默认「日常账本」 |

**交互规则：**

- 点击底部「+ 记账」按钮，底部抽屉式面板弹出（从下往上滑入动画）
- 数字键盘在抽屉下方，用户可直接输入金额
- 分类支持自定义，可修改名称和图标
- 保存成功后面板收起，列表自动更新

#### 5.2.4 账单列表

- 按日期分组，最新日期置顶，每日显示小计金额
- 每条记录展示：分类图标、分类名称、备注（截断显示）、金额（支出朱砂红 / 收入墨绿色）、时间
- 左滑条目显示：编辑 / 删除操作
- 支持按月份切换，顶部显示本月总收入、总支出、结余

#### 5.2.5 统计分析

| 图表类型 | 说明 | 维度 |
|----------|------|------|
| 饼图 / 环形图 | 各分类支出占比 | 月度 / 年度 |
| 柱状图 | 每日 / 每周收支对比 | 月视图 |
| 折线图 | 月度收支趋势 | 近 6 / 12 个月 |
| 排行榜 | 支出最多的 Top 5 分类 | 月度 / 年度 |

#### 5.2.6 预算管理

- 支持设置月度总预算和分类预算
- 预算进度条：已用 / 总预算（百分比 + 金额）
- 预警机制：达到 80% 时推送通知，达到 100% 时红色告警标识

#### 5.2.7 账本管理

用户可自定义管理收支分类。

**支出分类预设（9个）：**
餐饮、交通、购物、居住、娱乐、医疗、教育、人情

**收入分类预设（4个）：**
工资、奖金、理财、兼职

**功能说明：**

| 功能 | 说明 |
|------|------|
| 新增分类 | 点击「新增」按钮弹出编辑弹窗，输入分类名称并选择图标 |
| 删除分类 | 鼠标悬停显示删除按钮，点击可删除分类 |
| 去重检查 | 新增分类与现有分类（包括支出/收入）不能重名 |
| 持久化 | 分类数据存储于 localStorage |

**图标库（26个图标）：**
restaurant, directions_bus, shopping_bag, home, movie, health_and_safety, school, pets, flight, fitness_center, spa, music_note, book, coffee, local_bar, sports_esports, attach_money, savings, card_giftcard, redeem, trending_up, account_balance_wallet, payments, work, business_center, local_atm

#### 5.2.8 数据管理

- 导出格式：CSV、Excel（.xlsx）
- 导出范围：自定义日期区间
- 数据备份：支持导出完整备份文件（JSON），可导入恢复
- 数据删除：支持清空账本（需二次确认弹窗）

## 6. 视觉设计规范（水墨风主题）

> 本章节为 V1.0.1 新增内容，定义产品整体视觉语言。

### 6.1 设计理念

以中国传统水墨画为灵感，以「留白、墨韵、笔意」为核心，打造沉静、雅致、克制的东方美学界面。在工具类产品中传递「清心理财」的产品气质。

### 6.2 色彩系统

#### 主色板

| 色彩名称 | 色值 | 用途 |
|----------|------|------|
| 墨色（主文字） | `#1A1A1A` | 正文、标题 |
| 浓墨（强调） | `#2C2C2C` | 重要数字、按钮 |
| 淡墨（次级文字） | `#6B6B6B` | 说明文字、占位符 |
| 宣纸白（主背景） | `#F5F0E8` | 页面底色 |
| 素白（卡片背景） | `#FAF7F2` | 卡片、面板 |
| 水墨灰（分割线） | `#D4CCBC` | 分割线、边框 |

#### 功能色

| 色彩名称 | 色值 | 用途 |
|----------|------|------|
| 朱砂红（支出） | `#C0392B` | 支出金额、负向指标 |
| 松绿（收入） | `#2E7D5E` | 收入金额、正向指标 |
| 石青（交互主色） | `#2B6CB0` | 主要按钮、链接、高亮 |
| 赭石（预警） | `#B7610A` | 预算预警、提示信息 |

#### 深色模式（夜间）

| 色彩名称 | 色值 | 用途 |
|----------|------|------|
| 夜墨（背景） | `#121212` | 深色页面底色 |
| 宣墨（卡片） | `#1E1E1E` | 深色卡片背景 |
| 月白（主文字） | `#E8E0D0` | 深色模式正文 |

### 6.3 字体规范

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 大标题 | 28sp | Bold | 页面主标题 |
| 标题 | 20sp | SemiBold | 模块标题、金额主数字 |
| 正文 | 16sp | Regular | 列表内容、说明文字 |
| 辅助 | 13sp | Regular | 时间、标签、次级信息 |
| 微文 | 11sp | Regular | 角标、提示 |

- **中文字体优先级：** 方正书宋 → PingFang SC → 系统默认
- **数字字体：** DIN Alternate（金额数字使用等宽字体，对齐感更强）

### 6.4 图标风格

- 采用线性图标，笔触模拟毛笔运笔，线条粗细有变化（非均匀线宽）
- 图标尺寸：导航栏 24×24dp；分类图标 32×32dp
- 图标颜色默认使用淡墨色 `#6B6B6B`，选中态使用石青色 `#2B6CB0`

### 6.5 圆角与阴影

| 组件 | 圆角 | 阴影 |
|------|------|------|
| 卡片 | 8dp | `0 2px 8px rgba(0,0,0,0.06)` |
| 按钮（主要） | 4dp | 无阴影，用墨色描边替代 |
| 底部抽屉 | 顶部 32dp | `0 -4px 16px rgba(0,0,0,0.08)` |
| 输入框 | 4dp | 焦点态底部描边 2px 石青色 |

### 6.6 特色设计元素

- **水墨纹理背景：** 登录页及空状态页使用低透明度（8%）水墨晕染纹理图
- **笔触分割线：** 列表分组标题下方使用手绘感不规则线条替代直线
- **墨点加载动效：** 加载状态使用墨点扩散动效，取代旋转菊花
- **空状态插图：** 各页面空状态使用水墨风格毛笔插图（如空账本画一支空竹）

## 8. 关键用户流程

### 8.1 注册流程

1. 打开 App → 落地页
2. 点击「开启记账之旅」
3. 填写手机号 + 用户名 + 密码 + 确认密码
4. 勾选服务协议
5. 点击「注册」→ 校验通过 → 自动登录
6. 进入首页

### 8.2 登录流程

1. 打开 App → 落地页
2. 点击「立即登录」
3. 输入用户名/手机号 + 密码
4. 点击「登录」→ 验证通过 → 进入首页
5. 登录失败：显示「用户名或密码错误」提示（不区分是哪个错误，防止用户名探测）

### 8.3 找回密码流程（V1.0.3 完善）

1. 在登录页点击「忘记密码？」
2. 输入手机号
3. 点击「发送验证码」，收到验证码后输入
4. 输入新密码 + 确认新密码
5. 点击「重置」→ 验证通过
6. 进入成功页，点击「返回登录」

### 8.4 日常记账流程

1. 在首页点击 FAB「+」按钮
2. 抽屉从底部滑入
3. 输入金额（数字键盘）
4. 选择分类（支出/收入切换）
5. （可选）修改日期、添加备注
6. 点击确认按钮 → 完成，返回首页

### 8.5 账本管理流程

1. 进入「我的」Tab
2. 点击「账本管理」
3. 查看现有分类（支出/收入分类）
4. **新增分类**：点击对应类型的「新增」→ 输入名称 → 选择图标 → 确认（同名检测）
5. **删除分类**：鼠标悬停分类 → 点击删除按钮 → 分类移除

### 8.6 月度复盘流程

1. 进入「统计」Tab
2. 查看本月支出饼图 → 识别最大开销分类
3. 对比预算执行情况
4. 导出月度报告（CSV）备存

## 12. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| 用户数据丢失 | 低 | 高 | 本地自动备份 + 定期导出提醒 |
| 分类不满足用户习惯 | 中 | 中 | 提供完整自定义分类能力，内置 30+ 预设分类 |
| 用户粘性不足 | 中 | 高 | 每日记账提醒 + 月度财务报告 Push |
| 隐私合规问题 | 低 | 高 | 数据本地存储优先，明确隐私政策，不强制联网 |
| 水墨风格接受度差异 | 中 | 中 | 提供「简约白」备选主题，用户可自由切换 |
| 账号被暴力破解 | 低 | 高 | 连续失败 5 次锁定 10 分钟；密码强度校验 |
